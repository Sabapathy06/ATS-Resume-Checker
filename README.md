# ATS-Resume-Checker

ATS Resume checker - This will help to improve your Resume and optimize it for Applicant Tracking Systems (ATS).

## Features

- **ATS Resume Analysis**: Deep analysis across formatting, section completeness, keyword matching, and readability.
- **Interactive Scoring**: Real-time score gauge, radar chart breakdown, and dimensional metrics.
- **Resume Builder**: Built-in resume builder with customizable templates and instant live preview.
- **Role Matching & Comparison**: Compare your resume against target job descriptions and roles.
- **Export Options**: Download comprehensive ATS analysis reports and formatted resumes as PDF.
- **User Dashboard & History**: Save and track your resume analyses over time.

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend / APIs**: Vercel Serverless Functions (`/api`), Supabase client integration
- **Document Processing**: PDF parsing and generation with `jspdf` and `html2canvas`

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sabapathy06/ATS-Resume-Checker.git
   cd ATS-Resume-Checker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
